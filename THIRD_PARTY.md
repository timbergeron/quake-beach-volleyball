# Upstream credits

This project is licensed under GPL-2.0-or-later. A copy of the license is in
`LICENSE`.

- `resources/anorms.h` is the Quake alias-model normal table, copied without
  changes from [QSS-M](https://github.com/timbergeron/QSS-M/blob/qsrebase/Quake/anorms.h).
  Copyright (C) 1996–1997 id Software, Inc.; GPL-2.0-or-later. Its original notice
  is preserved. The table gives the generated models correct lighting.
- `src/defs.qc` adapts the minimal NetQuake ABI declarations from QSS-M's
  `Misc/ssqcharness/src/defs.qc`, with shared server/client declarations and
  volleyball-specific extensions added on 2026-10-04. The QSS-M source is
  distributed under the GNU GPL; these declarations remain under GPL-2.0-or-later.
- [FTEQCC](https://github.com/fte-team/fteqw) and
  [ericw-tools](https://github.com/ericwa/ericw-tools) are external build tools.
  Their binaries are not bundled here.

The sand and sea artwork was supplied by the project maintainer as
`Seamless Stylized Beach Sand Texture.png` and `Moody Retro Water Texture.png`.
The prepared 1024×1024 TGA copies are in `resources/textures`; practice markings
are generated over the supplied sand. The court, remaining textures, skybox,
ball, shadow, marker, athlete models, bitmap HUD font, and contact sounds
are generated from this project's Python source. No Quake PAK files, stock models,
or stock textures are distributed. A local Quake installation supplies the
palette during the build.

The MD3 volleyball and its RGB skin are original procedural assets generated by
`ball_assets.py`, under GPL-2.0-or-later. The white/yellow/blue beach-ball palette
and curved panel style take visual inspiration from the
[Mikasa BV550C](https://mikasasports.com/shop/beach-volleyball/bv550c/).
No Mikasa photography, logos, textures, or mesh data are included. The panel
layout and BEACH wordmark are this project's own artwork.

The net MD3 and 1024×1024 material atlas are original procedural assets generated
by `net_assets.py`, under GPL-2.0-or-later. Dimensions and construction follow the
[FIVB 2025–2028 beach volleyball rules](https://www.fivb.com/wp-content/uploads/2025/02/FIVB-BeachVolleyball_Rules2025_2028-EN-v01.pdf).
No FIVB logos, photographs, textures, diagrams or mesh data are included. This
project is independent and is not affiliated with FIVB.

The controls take inspiration from Virtua Tennis. No Sega assets or code are
used. This is an independent mod and is not affiliated with Sega or id Software.

The Norwegian-inspired male athletes are original
procedural meshes, animation rigs and textures generated by `player_assets.py`,
under GPL-2.0-or-later. Anders Mol and Christian Sørum supply a visual reference
for athletic proportions, Norway kit, caps and full mirrored sun shields. No
photographs, scans, sponsor logos or third-party character meshes are included.
The animations are artist-authored poses, not motion capture. See
[the player notes](docs/player.md) for reference links.

The first-person hands use the CC0 MakeHuman base mesh, young Caucasian male
anatomy target, default skeleton joint locations and weights, plus the system
asset pack's `young_lightskinned_male_diffuse.png` skin. Only trimmed hand and
forearm data and a cropped skin atlas are included. The source revision is
`a8bc2d54ff0ac92e78ff71431b1023eda42bf482`; input hashes are recorded in
`resources/hands/hand-rig.json`. MakeHuman assets are explicitly CC0:
[asset license](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.md),
[system asset pack](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html).
The skin material credits Data Collection AB, Joel Palmius, and Jonas Hauquier.
The [CC0 text](resources/hands/LICENSE.CC0.txt) is included in the game package.
No MakeHuman application code is copied. Extraction, mesh adaptation, skinning,
camera framing and all volleyball motions are original code and authored poses
under GPL-2.0-or-later in `prepare_hand_source.py` and `hand_assets.py`.

Player MD3 export and validation use
[md3harness](https://github.com/timbergeron/md3harness), GPL-2.0-or-later, as an
external Python source dependency. Its exporter is not copied into this project.

Bot candidate-shot evaluation, emergency dives and contact separation also take
design inspiration from Kyutae Lee's
[Pikachu Volleyball reconstruction](https://github.com/gorisanson/pikachu-volleyball/blob/main/src/resources/js/physics.js).
These systems are original QuakeC implementations using this mod's 3D flight and
contact code. No source code, sprites, sounds or other assets from that project
are included.

Float-versus-speed serve design is informed by Reiser et al. (2020),
[study of float serves in beach and indoor volleyball](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2020.559277/full).
The bounded wake approximation and platform-rebound receive code are original
implementations. No paper text, data, or third-party simulation code is bundled.
